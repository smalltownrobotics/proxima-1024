# Contributing

Issues and pull requests are welcome.

1. Keep the simulation's mechanical effects explicit and testable.
2. Label speculative narrative as possibility rather than established fact.
3. Do not commit API keys, campaign saves, provider transcripts, personal data, or generated runtime logs.
4. Run the Python test suite and `npm run build` before opening a pull request.

By contributing, you agree that your contribution may be distributed under the MIT License.
